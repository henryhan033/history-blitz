# T02 · 내가 설계한 미니게임 — HISTORY BLITZ

## 게임 개요
30초 동안 한국사 객관식 문제를 최대한 많이 맞히는 속도 퀴즈입니다.

## 핵심 루프
게임 시작 → 문제 표시 → 1~4번 보기 선택 → 즉시 정답/오답 피드백 → 다음 문제 → 30초 종료 → 최종 점수 → 다시 시작

## T02 대응
- 공개 결과물: 정적 HTML/CSS/JS
- 소스 저장: 전체 프로젝트 파일
- 30초 핵심 루프: 시작부터 시간 종료까지 한 세션이 짧게 끝남
- PC 경계: 반응형 레이아웃으로 1366×768 및 1920×1080 대응
- 연속 입력: 1~4번 키는 현재 한 문제에 한 번만 처리하고, 답변 중 버튼을 비활성화
- 포커스/탭 이탈: 자동 일시정지하며 진행 상태 보존
- 10분 안정성: 매 문제 DOM을 교체하고 불필요한 타이머/이벤트 누적을 만들지 않음
- 난이도 실험: `DIFFICULTY.difficultyMode` 하나만 `normal` ↔ `hard`로 변경하며 같은 30초 규칙과 조작을 유지
- 저장: 최고 점수 및 접근성 설정만 localStorage 저장
- 손상 저장값: JSON/형식 검증 실패 시 기본값으로 복구
- 효과 선택권: '정답' 사건에서만 정답 효과음이 1회 실행되며, 효과음 끄기/움직임 줄이기를 제공
- 개인정보·비밀값: API 키, 비밀번호, 개인정보 저장 없음

## 로컬 실행
index.html을 브라우저로 열거나 VS Code Live Server로 실행합니다.

## 제출 전 확인
1. 새 시크릿 창에서 결과 URL을 열어 로그인 없이 실행합니다.
2. 시작 → 보기 선택 → 정답/오답 → 다음 문제 → 30초 종료 → 다시 시작을 검사합니다.
3. 1366×768과 1920×1080에서 가로 스크롤 및 잘림이 없는지 확인합니다.
4. 1~4번 키를 빠르게 여러 번 눌러도 한 문제의 답변이 중복 처리되지 않는지 확인합니다.
5. 창 포커스를 빼면 일시정지되고 돌아오면 재개되는지 확인합니다.
6. Console에 빨간 오류가 없는지 확인합니다.
7. localStorage 값을 비우거나 손상시킨 뒤 새로고침해도 정상 시작되는지 확인합니다.
